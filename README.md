# Stari-am Homebrew tap

```sh
brew install --cask stari-am/tap/griasa
```

[Griasa](https://github.com/Stari-am/griasa) records your meetings on your own Mac, finds who promised what, and briefs you before the next call. Free and open source (GPL-3.0), macOS 14+.

The cask is updated by Griasa's release script with each release.
